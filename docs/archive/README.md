# Archivo Histórico de Documentación

Esta carpeta almacena documentos exploratorios y reportes de etapas preliminares del proyecto. Se preservan para mantener la trazabilidad histórica del desarrollo, pero han sido formalmente superados por la arquitectura y los contratos vigentes:

* **`COMPARACION_EQUIPO.md`**: Comparaciones exploratorias de la primera semana de pruebas grupales. Superado por [`EXPERIMENTO_CUATRI_MODELO_STACKING.md`](../EXPERIMENTO_CUATRI_MODELO_STACKING.md).
* **`RESULTADOS_IAN.md`**: Primera corrida preliminar (`ian_v1`). Superado por [`RESULTADOS_OFICIAL.md`](../RESULTADOS_OFICIAL.md).
* **`EXPERIMENTOS_PCA.md`**: Script inicial de reducción de dimensionalidad exploratoria. Superado por la ingeniería de features y los scores de anomalías no supervisadas de [`scores_anomalias.parquet`](../../data/features/scores_anomalias.parquet).
